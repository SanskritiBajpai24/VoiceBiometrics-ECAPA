# 🎙️ VoxAuth-AI 
A deep learning voice authentication system using the **ECAPA-TDNN** architecture.

## 🚀 How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python main.py`

## 🛠️ Features
- Real-time voice enrollment via microphone.
- Speaker verification using Cosine Similarity.
- Fail-safe audio loading (handles Windows backend issues).
